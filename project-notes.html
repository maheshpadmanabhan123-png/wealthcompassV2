Run & deploy

Open a file, or push a branch.

Because there is no build step, local preview and production use the same files.

01

Preview locally

Open index.html directly, or serve the folder for accurate paths.

  • 1python -m http.server 8080
  • 2Visit localhost:8080
02

Commit the repo

The folder is already a git repository with one commit on main.

  • 1git add -A
  • 2git commit -m "update"
03

Publish to Pages

Push to GitHub, then choose GitHub Actions as the Pages source. The workflow does the rest.

  • 1git remote add origin <url>
  • 2git push -u origin main

Customising: colours and type live in the CSS custom properties at the top of style.css. Demo portfolio values, risk profiles and currency rates live in main.js.
